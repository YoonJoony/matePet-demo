# matePet demo — 반려동물 교배·입양 매칭 앱 데모

내 주변의 **교배 상대**와 **입양 가족**을 지도에서 찾고, 동물병원·반려용품·반려동물 미용 같은 주변 시설도 함께 탐색하는 앱의 웹 데모입니다.
Expo(React Native) + Expo Router로 만들었고, 지금은 **웹 미리보기 전용**입니다.

## 주요 기능

| 영역 | 내용 |
|---|---|
| 홈 (지도) | 등록 글을 원형 프로필 마커로 표시 (목적별 테두리·`교배`/`입양` 배지, 성별 배지). 가까운 마커는 숫자 묶음으로 합치고, 누르면 확대하거나 같은 동네 글 목록을 보여 줌. 하단 시트에서 `동물 찾기 / 주변 시설` 전환 |
| 글 목록 | 검색 중심에서 가까운 순, 모집 중·상담 중 글만 표시 |
| 지역 설정 | 홈·글 목록의 지역 버튼과 등록 화면의 '변경'에서 실제 행정동을 고름. 현재 위치에서 탐색(가장 우선) · 내 위치(또는 선택한 지역) 주변 동네 · 동네 이름 검색 · 지도에서 선택(고정 핀). 홈 탐색 위치와 글 등록 동네는 따로 적용되고, 사용자 기본 동네는 바뀌지 않음 |
| 필터 | 목적·종류·품종·성별·거리(두 손잡이 슬라이더, 기본 0~20km, 최대 100km). 지도와 목록이 같은 필터를 공유하고, 결과가 없으면 거리 넓히기·조건 초기화를 제안 |
| 주변 시설 | 동물병원·반려용품·반려동물 미용 (Google Places, 반경 3km). 시설 상세(주소·영업 여부·사진·후기)와 전화·길찾기 |
| 글 등록·수정 | 교배/입양 등록 폼, 필수 항목 검사, 임시저장. 작성자 본인 글만 수정·상태 변경(모집 중/상담 중/완료/일시 중지) 가능 |
| 채팅 | 샘플 대화와 이 기기 안에서만의 메시지 전송, 읽지 않은 수 배지 |
| 프로필 | 내 등록 글, 찜한 글, 관심 시설 수 |

### 위치·개인정보 원칙

- 지도에 보이는 위치는 실시간 위치가 아니라 **등록한 동네의 중심점**입니다. 상세 주소는 저장만 하고 화면에 보여 주지 않습니다.
- 거리는 기준점(현재 위치, 모르면 기본 지역)과 동네 중심점 사이의 직선거리이며 `1km 이내`, `약 N km`로 반올림해 표시합니다.

## 실행 방법

필요: Expo SDK 58에 맞는 Node.js(검증 환경: 24.21.0), Google 지도 표시용·Places 서버용 키 각각 1개, 카카오 REST API 키(로컬 API — 좌표→행정구역)

```bash
npm install
```

프로젝트 루트에 `.env` 파일을 만들고 키를 넣습니다. (`.env`는 저장소에 올라가지 않습니다.)

```env
GOOGLE_MAPS_BROWSER_API_KEY=지도_표시용_별도_키
GOOGLE_REST_API_KEY=Places_서버용_키
KAKAO_REST_API_KEY=발급받은_키
```

지도 표시용 키는 브라우저에 공개됩니다. Google Cloud에서 **Maps JavaScript API만 허용**하고 HTTP 리퍼러에 로컬·배포 도메인을 등록하세요. Places 서버용 키와 동일한 키를 넣으면 `/api/maps-config`는 503을 반환하며 키를 공개하지 않습니다. `.env.example`에는 변수 이름만 있습니다.

서버 배포 현황과 다음 작업은 [서버 배포 Claude 인계 문서](./서버-배포-클로드-인계.md)를 확인하세요.

```bash
npm run web
```

브라우저에서 `http://localhost:8081`을 엽니다. 휴대폰 화면 크기(예: 375×812)로 보는 것을 권장합니다.
위치 권한을 허용하면 현재 위치 기준으로, 허용하지 않으면 기본 동네(도촌동 — 성남시청이 있는 행정동) 기준으로 보여 줍니다.

## 기술 구성

- Expo SDK 58, React Native 0.88, Expo Router (`web.output: "server"` — API 라우트 사용)
- 지도: Google Maps JavaScript API (다크 모드), HTML 오버레이 마커
- 지도 키: `GOOGLE_MAPS_BROWSER_API_KEY`만 `/api/maps-config`에서 브라우저로 전달합니다.
- 장소: Google Places API (New). `GOOGLE_REST_API_KEY`는 서버 API 라우트(`src/app/api/*+api.ts`)에서만 사용하고 브라우저에는 노출하지 않습니다. 검색 결과는 저장하지 않습니다.
- 호출 제한(공개 배포용, `src/server/apiGuard.ts`): 장소 검색·상세·사진과 동네 확인 API는 다른 사이트에서 온 요청을 거부하고, 접속자별 1분 횟수와 API별 하루 전체 횟수를 제한합니다. 서버 메모리로 세므로 서버 인스턴스마다 따로 세는 최선 노력 제한이며, 확실한 상한은 Google Cloud 콘솔 할당량으로 겁니다. 장소 상세 사진은 처음 3장만 불러옵니다.
- 상태: React Context (글·찜·필터·채팅·지도 상태), 모두 메모리 저장

## 지역(행정동) 데이터

- 좌표가 속한 행정동: 카카오 로컬 `coord2regioncode`의 행정동(`region_type` H) 결과를 쓰고, 법정동(B)은 쓰지 않습니다. 키는 서버(`src/server/kakaoLocal.ts`)에서만 씁니다.
- 주변 동네 목록·동네 이름 검색: 아래 행정동 경계 데이터로 서버에서 직접 계산합니다. 전체 경계는 브라우저로 보내지 않습니다.
- 경계 강조: 홈 지도는 선택한 동네(또는 기본 동네)의 경계를, 지도에서 선택 화면은 핀 위치 조회가 끝난 동의 경계를 표시합니다. 필요한 한 동의 실제 경계만 받아 그리고(`/api/regions/boundary`), 검색 결과를 경계 안으로 제한하지는 않습니다.
- 지역 식별자는 행정안전부 10자리 행정기관코드입니다. 카카오 행정동 코드와 같은 체계임을 지원 지역 546개 행정동 전체의 대표 위치로 대조해 확인했습니다.
- 지원 지역(34개 시·군·구, 546개 행정동): 서울 전체(25개 구), 성남시(수정·중원·분당구), 과천시, 의왕시, 하남시, 광주시, 용인시 기흥·수지구. 그 밖의 지역은 '지원하지 않는 지역'으로 안내합니다.
- 기준일: **2026-10-01** (`HangJeongDong_ver20261001.geojson`, 좌표계 WGS84)

> 본 데이터는 통계청 통계지리정보서비스(SGIS, https://sgis.kostat.go.kr)에서 공공누리 제1유형으로 개방한 행정동 경계를 가공한 것이며(가공: vuski/admdongkor, https://github.com/vuski/admdongkor), CC BY 4.0으로 배포됩니다.

갱신 방법: [admdongkor](https://github.com/vuski/admdongkor)에서 최신 `HangJeongDong_verYYYYMMDD.geojson`을 내려받아 저장소 밖에 두고 아래를 실행합니다. `src/server/regions-data.json`(경계)과 `src/data/regionSamples.json`(샘플 글의 행정동)이 다시 만들어집니다. 지원 지역은 스크립트의 `SUPPORTED_SGG`에서 바꿉니다.

```bash
node scripts/build-regions.mjs <내려받은 geojson 경로>
```

## 폴더 구조

```text
src/
  app/            화면과 API 라우트 (Expo Router)
    (tabs)/       하단 탭: 홈 지도, 글 목록, 커뮤니티, 채팅
    api/          Google Places 중계 서버
  components/     지도·하단 시트·반려동물 UI 조각
  data/           샘플 데이터와 거리·필터 계산
  state/          Context 상태
  server/         서버 전용 Google Places 도우미
public/pets/      샘플 프로필 사진
```

## 데모의 한계

- 글·찜·채팅·임시저장은 메모리에만 있어 **새로고침하면 샘플 상태로 돌아갑니다.**
- 샘플 글은 성남시와 주변 지역(분당·수서·문정·죽전) 기준입니다. 샘플 프로필 사진은 생성 이미지입니다.
- 채팅은 실제 전송·알림 없이 이 기기에서만 동작합니다. 커뮤니티 탭은 준비 중입니다.
- 지도는 웹에서만 그립니다. iOS·Android 앱에서는 지도 연동 작업이 더 필요합니다.
- 반려용품(`pet_store`) 검색에는 구글 분류상 분양샵·수족관이 함께 나올 수 있습니다.
- 행정동 경계 근처(수십 m)에서는 카카오와 통계청 경계 자료가 서로 다른 동을 가리킬 수 있습니다. 이때는 카카오 판정을 따릅니다.
